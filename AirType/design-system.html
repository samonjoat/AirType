Accent Rules

ElementAccent Treatment
History timeline dotsLogo blue. Light uses #4860FF; dark uses theme accent #7C8CFF.
Settings latency barsLogo blue/accent only. Each segment keeps a readable minimum width and shows its latency value directly in white code text.
Word activity/historyOne-color line chart. No multi-color bars.
Current streakRestrained fire gradient. It may use orange, but graphite remains dominant.
Capsule HUDStrict graphite. No blue, red, green, or fire treatment except existing state clarity where unavoidable.
ToastsNo red/green left border. Use neutral frame with semantic text/icon only.
Focus / selection bordersNeutral graphite FocusRingBrush (light #8A8175, dark #8A8A8A) — never logo-blue. The logo-blue accent is reserved for data-viz (timeline dots, latency bars, charts) and the logo mark.
