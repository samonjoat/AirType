What Changed

Visual Rounded bottom corners on dropdown (0 0 14px 14px) instead of sharp 0px corners, creating a continuous capsule shape when open.
UX Checkmark indicator on the selected item alongside the existing inverted-color selection. Adds a clear visual cue for which item is active.
UX Inverted selection preserved (white-on-black / black-on-white) — the selected item still uses TextPrimaryBrush background with BgBrush text, matching both themes naturally.
Polish Chevron rotation animation (180deg) on open gives directional feedback.
Polish Hover state on closed combo darkens the border (BorderBrush -> TextSecondaryBrush) before opening, adding an interaction hint.
Polish Muted chevron color (TextMutedBrush) instead of TextPrimaryBrush reduces visual noise in the resting state.
