# Contributing to AirType

AirType accepts fixes, tests, documentation, accessibility improvements, and
well-scoped features through GitHub pull requests. Discuss large behavioral or
architectural changes in an issue before investing in an implementation.

## License

AirType's first-party source and reproducible first-party assets are licensed
under `AGPL-3.0-only`. By contributing, you agree that your contribution may be
distributed under that license. No copyright assignment or contributor license
agreement is required.

Do not submit code, recordings, fonts, images, model weights, or other material
unless you have the right to distribute it under terms compatible with this
repository. Identify third-party material and its license in the pull request.

## Developer Certificate of Origin

Every commit must include a `Signed-off-by` line certifying the Developer's
Certificate of Origin 1.1 in `DCO.txt`. Create it with:

```text
git commit -s
```

The sign-off uses your real name and an email address you are entitled to use.
It is a certification of contribution rights, not a cryptographic signature.

## Contribution Requirements

1. Branch from the current public default branch.
2. Keep each commit focused on one independently reviewable issue.
3. Add or update tests for behavioral changes.
4. Run the clean build and test commands documented in `README.md`.
5. Update public documentation when behavior, privacy, storage, or packaging changes.
6. Open a pull request that explains the problem, root cause, solution, and verification.

Contributions and community participation are governed by
`CODE_OF_CONDUCT.md`. Use the private reporting method documented there for
conduct reports; do not publish sensitive reports in an issue.

## Branding

The AGPL source license does not grant trademark rights. Forks and modified
distributions must follow `TRADEMARKS.md` and must not imply that they are
official AirType releases.
